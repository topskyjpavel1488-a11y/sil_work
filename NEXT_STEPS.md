## 7. Идеи для обновлений после выхода

Отложено владельцем 14.10.2026 — делать после релиза, по отзывам игроков. Почти без новой графики.

1. **Часы показывают настоящее время:** у восстановленных часов кодом нарисованы стрелки, они идут по часам устройства; тиканье — синтезированный звук.
2. **Радио включается нажатием:** нажали на починенное радио — играет мелодия, ещё раз — замолкает.
3. **Лампу можно включать и выключать** нажатием (тёплый свет уже есть в коде).
4. **Комната живёт по времени суток:** утром свет прохладнее, вечером теплее, ночью темнее и горит лампа (цветной слой по часам устройства).
5. **Реакция на нажатие:** восстановленная вещь покачивается и отзывается подходящим звуком из уже имеющихся.
6. **Письма деда:** карточка-письмо (текст поверх уже нарисованной картинки) после каждой второй комнаты или одно большое через несколько комнат — продолжает историю вступления. Имеет смысл, когда комнат станет больше двух.
