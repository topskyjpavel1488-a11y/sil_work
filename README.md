# Тихая мастерская

Уютная 2D-игра для Яндекс Игр: восстановление дедушкиной мастерской. Стек: TypeScript, Phaser 3, Vite, Vitest.

## Установка

Нужны Node.js (LTS) и Git.

```bash
npm install
```

## Команды

| Команда | Что делает |
| --- | --- |
| `npm run dev` | dev-сервер с перезагрузкой, http://localhost:5173 |
| `npm run build` | проверка типов, сборка в `dist/`, проверка сборки (имена файлов, размер) |
| `npm run preview` | раздаёт собранный `dist/`, http://localhost:4173 |
| `npm test` | тесты |
| `npm run lint` | линтер |

## Как запустить сборку

Открывайте игру через сервер, а не двойным щелчком по `dist/index.html`. Сборка подключает скрипт как ES-модуль, а браузеры на основе Chromium не загружают модули со страниц, открытых с диска (`file://`).

- На своём компьютере: `npm run build`, затем `npm run preview`.
- С телефона в домашней сети: `npm run preview`, затем откройте на телефоне адрес `Network:` из вывода команды.
- Друзьям: выложите содержимое `dist/` на любой статический хостинг (например, GitHub Pages) и отправьте ссылку.

Сборка `test` (по умолчанию) работает без SDK и рекламы, прогресс хранится в `localStorage`.
