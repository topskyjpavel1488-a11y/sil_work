# Чек-лист перед отправкой на модерацию

Пункты из раздела 12.3 спецификации. Требования платформы сверяйте с актуальной страницей: https://yandex.ru/dev/games/doc/ru/concepts/requirements

Состояние на 11 октября 2026, коммит этапа M8. «Проверено автоматически» — это сделано тестами, `validate` или проверкой сборки; всё остальное проверяет владелец по шагам из `TESTING.md`.

| № | Пункт | Состояние |
| --- | --- | --- |
| 1 | SDK подключён, `LoadingAPI.ready()` вызывается, когда главный экран готов к игре | Код готов, адаптер покрыт тестами с поддельным SDK. **Проверить в черновике:** консоль без ошибок, нет уведомления о WebGL |
| 2 | `index.html` в корне архива; имена без пробелов и кириллицы; размер ≤ 100 МБ; нет адресов S3 Яндекса и внешних ссылок | Проверено автоматически при каждой сборке. Архив: 0,32 МБ, распакованный — 1,21 МБ |
| 3 | Гостевой вход работает; вход через Яндекс ID только по кнопке | Код готов: вход только по кнопке в настройках, рядом объяснение выгоды. **Проверить в черновике** гостем и после входа |
| 4 | Звук замолкает при потере фокуса и во время рекламы; на время рекламы игра на паузе | Код готов, логика паузы покрыта тестами. **Проверить на устройствах** |
| 5 | Лонгтап и выделение не открывают меню; нет прокрутки; узкий и широкий экраны, поворот, сворачивание | Отключено в коде, широкий и узкий экраны проверены в браузере на ПК. **Проверить на телефонах** |
| 6 | Сохранения работают после обновления страницы и повторного открытия браузера | Проверено в браузере на ПК. **Проверить на телефонах и в черновике** (облако) |
| 7 | Реклама только через SDK; задержка ≤ 2 с; подписи наград понятны | Код готов: показ вызывается сразу после действия, без промежуточных экранов. **Проверить в черновике** |
| 8 | Язык определяется через SDK; тексты на русском без ошибок | Код готов. **Вычитать русские тексты**, английский перевод — черновой |
| 9 | Игра выглядит законченной; финальные графика и звук подключены | **Не выполнено:** в игре заглушки. Нужны финальные ассеты (README, раздел про графику) |
| 10 | В контенте нет политики, войн, религии и мата; права на материалы подтверждены | Тексты проверены при написании; сторонних ассетов нет (`assets/LICENSES.md`). Права на финальные ассеты — при их подключении |
| 11 | Игра не копирует другую из каталога (3.6) | **Владелец:** проверить каталог на похожие игры и название |
| 12 | Поля черновика заполнены; иконка и обложка не скриншоты; на скриншотах ≥ 70% геймплея; нет рамок и элементов интерфейса Яндекс Игр; тексты в полях не дублируются | **Владелец** |
| 13 | Заявлены только проверенные платформы; телевизоры не заявлять | **Владелец.** Портретная игра на ПК правилами разрешена (поле на ПК растягивается по высоте, соотношение сторон 1,78 ≤ 2 — пп. 1.6.2.1–1.6.2.2). Ограничение только у промо: по странице «Заполнение черновика» десктопные скриншоты — только альбомные, а по п. 5.1.1.2 геймплей занимает ≥ 70% площади скриншота; наша колонка в альбомном кадре — около трети. Видео проверяется по длительности (п. 5.1.1.3: ≥ 70% времени — реальный геймплей), поэтому горизонтальное видео с вертикальной колонкой подходит. Варианты для «Десктопа»: спросить поддержку; коллаж из трёх вертикальных экранов в одном кадре 16:9 (≈ 95% геймплея, но может не пройти как «снятый с устройства»); заявить на старте только мобильные платформы. В поле «Ориентация» черновика указать портретную |

После публикации рейтинг игры должен держаться выше 30: если в течение 3 недель он 30 или ниже, игру снимают с публикации. Первые примерно 2 недели у новых игр не учитываются.

## Что готовит владелец (12.2)

- [ ] Финальная графика и звук (по ключам `assets/manifest.json`), строки в `assets/LICENSES.md`
- [ ] Иконка, обложка, скриншоты
- [ ] Название и описания: одинаковое название во всех материалах, уникальное в каталоге
- [ ] Возрастной рейтинг по финальному контенту
- [ ] Категории (не больше двух) и теги
- [ ] Поле «Как играть»
- [ ] Контактный адрес
- [ ] Проверка каталога на похожие игры
- [ ] Загрузка архива в консоль, опция «Игра использует облачные сохранения», модерация (обычно 3–5 рабочих дней)
