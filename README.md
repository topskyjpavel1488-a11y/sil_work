# Тихая мастерская

Уютная 2D-игра для Яндекс Игр: игрок разбирает завалы, объединяет детали и чинит вещи в дедушкиной мастерской. Стек: TypeScript, Phaser 3, Vite, Vitest. Спецификация — документ «Тихая мастерская — спецификация для реализации» (v0.5).

## Установка

Нужны Node.js (LTS) и Git.

```bash
npm install
```

## Команды

| Команда | Что делает |
| --- | --- |
| `npm run dev` | dev-сервер с перезагрузкой, http://localhost:5173 |
| `npm run build` | сборка `test` в `dist/`: без SDK и рекламы; проверка типов и проверка сборки |
| `npm run build:release` | сборка `release` в `dist/`: с SDK Яндекс Игр и рекламой |
| `npm run package` | сборка `release` и архив `tikhaya-masterskaya.zip` для загрузки в консоль |
| `npm run preview` | раздаёт собранный `dist/`, http://localhost:4173 |
| `npm test` | тесты |
| `npm run lint` | линтер |
| `npm run validate` | проверка контента: ссылки, тексты, ассеты, раскладка, баланс, прохождение ботом |
| `npm run simulate` | бот проходит игру целиком и печатает ход и итоговые числа |
| `npm run layout` | редактор раскладки, http://localhost:5174 |
| `npm run images` | готовит графику: из `assets/source/images/` в `assets/files/images/` и манифест |

Каждая сборка заканчивается проверкой `dist/`: `index.html` в корне, имена файлов латиницей без пробелов, нет адресов S3 Яндекса и внешних ссылок, размер не больше 100 МБ.

## Две сборки

- **test** (`npm run build`) — для показа друзьям и наблюдения за игроками. Нет SDK, рекламы и кнопок наград; прогресс хранится в `localStorage` браузера.
- **release** (`npm run build:release`, `npm run package`) — для Яндекс Игр. Подключает `/sdk.js`, определяет язык, сохраняет прогресс в облако для вошедших игроков, показывает рекламу. Вне платформы SDK не загрузится: игра всё равно запустится на локальном режиме, а в консоли будет ошибка 404 про `sdk.js` — это нормально только при локальном запуске.

## Как запустить сборку

Открывайте игру через сервер, а не двойным щелчком по `dist/index.html`: сборка подключает скрипт как ES-модуль, а браузеры не загружают модули со страниц, открытых с диска.

- На своём компьютере: `npm run build`, затем `npm run preview`.
- С телефона в домашней сети: `npm run preview` и адрес `Network:` из вывода команды.
- Друзьям: выложите содержимое `dist/` (сборка `test`) на любой статический хостинг, например GitHub Pages, и отправьте ссылку.

## Загрузка на Яндекс Игры

1. `npm run package` — появится `tikhaya-masterskaya.zip` (index.html в корне архива).
2. В консоли разработчика создайте черновик и загрузите архив.
3. Включите в черновике опцию «Игра использует облачные сохранения».
4. Пройдите `RELEASE_CHECKLIST.md`.

## Контент

Контент лежит в `src/data/*.json`, тексты — в `src/i18n/ru.json` и `src/i18n/en.json`, ключи графики и звука — в `assets/manifest.json`, раскладка экранов — в `src/data/layout.json`. После любой правки запускайте `npm run validate`: он называет, что именно нарушено. Как добавлять объекты, зоны и находки — раздел 14 спецификации.

## Как подключить настоящую графику и звук

Список всех ассетов с размерами и промптами для нейросетей — в `assets/ART_BRIEF.md`.

Сейчас вместо графики — цветные заглушки, вместо звуков — короткие синтезированные тона. Код ссылается только на ключи из `assets/manifest.json`, поэтому замена не требует правок кода:

1. Положите файл в `assets/files/` (латиница, без пробелов), например `assets/files/objects/workbench_0.png`.
2. В `assets/manifest.json` у нужного ключа замените `"file": null` на путь внутри `assets/files/`: `"file": "objects/workbench_0.png"`.
3. Запишите источник и лицензию в `assets/LICENSES.md`.
4. `npm run validate` и `npm run dev` — проверьте на экране.

Картинка растягивается на прямоугольник из `layout.json`; размеры можно поправить в редакторе раскладки. Музыки в игре пока нет: канал и переключатель в настройках есть, файл подключается так же, когда он появится.

## Редактор раскладки

`npm run layout` открывает в браузере поле 720×1280 со всеми элементами выбранного экрана (список «Экран»: мастерская, разбор каждой зоны, стол, журнал). Элементы перетаскиваются мышью, размер меняется за углы, всё привязано к сетке 8 px; стрелки сдвигают выбранный элемент на 8 px. Красная рамка — хотспот меньше 96×96. «Сохранить» записывает `src/data/layout.json`; чтобы увидеть результат, обновите игру (`npm run dev`). Редактор в сборку игры не попадает.

## Для разработки

В режиме `npm run dev` на главном экране есть красная кнопка DEV+: по 5 единиц каждого ресурса и «Набор крепежа». В сборки она не попадает. Сбросить прогресс можно в настройках игры (⚙ → «Сбросить прогресс»).
