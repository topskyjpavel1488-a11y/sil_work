# План проверки для владельца

Что я (Claude Code) проверил сам и что остаётся проверить вам. Всё, что требует настоящего телефона, площадки Яндекс Игр, рекламы или слуха, в этот список и вынесено.

## Что уже проверено автоматически

- 50 тестов: правила разбора, стола, ремонта, сохранений, обучения, наград, правил показа рекламы, адаптера Яндекс Игр (на поддельном SDK).
- `npm run validate`: ссылки в данных, тексты на двух языках, ключи ассетов, раскладка всех экранов, баланс с запасом 25% на каждом шаге ремонта, бот проходит игру до финала (стол занят максимум на 9 клеток из 20).
- Каждая сборка: `index.html` в корне, безопасные имена файлов, нет S3 и внешних ссылок, размер 1,21 МБ (цель ≤ 30 МБ).
- В браузере на ПК (экран телефона 540×960 и широкий экран): обучение от начала до конца, разбор, переполнение стола, перенос и объединение обоими способами, ремонт, карточки находок, журнал, финал, настройки, сброс, перезагрузка страницы, кнопки наград в режиме `release` на локальной заглушке. Ошибок в консоли нет.

## 1. Прототип: тест на людях (сборка `test`)

Подготовка: `npm run build`, выложить `dist/` на хостинг (README) или `npm run preview` в домашней сети. Дайте телефон 5–10 людям без объяснений. Записывайте, где они остановились, запутались или нажимали не туда.

Ориентиры успеха (раздел 11.3 спецификации, не отраслевые нормы):

| Что смотреть | Хорошо | Плохо |
| --- | --- | --- |
| Понимает первую цель | Сам заходит в «Кучу у двери» по подсказке | Тычет в разные места, не замечает подсказку |
| Понимает связь награды и ремонта | Возвращается к верстаку, когда хватает древесины | Не понимает, зачем собирает |
| Объединение | Понимает «перетащи шайбу на такую же» с первого-второго раза | Не может объединить без подсказки |
| Первый ремонт | Ремонт ощущается наградой | «Бухгалтерия»: скучно считать |
| Хочет продолжить | Сам идёт дальше после обучения | Бросает после первого ремонта |
| Уровни деталей | Не застревает из-за нехватки «Набора крепежа» | Сливает всё в высокие уровни и не может починить (пункт 8 из нашего обсуждения) |

Отдельно спросите: понятны ли заглушки-прямоугольники и подписи, удобен ли стол 4×5, не мешает ли облачко обучения, слышны ли звуки.

## 2. Устройства (сборка `test`, раздел 10.2)

Устройства: бюджетный Android, iPhone, ПК с мышью. На каждом:

- [ ] Первый запуск: обучение появляется, каждый шаг можно пропустить
- [ ] Игра занимает экран, нет прокрутки страницы, всё доступно одной рукой (телефон)
- [ ] Лонгтап по игре не открывает меню, текст не выделяется
- [ ] Перетаскивание на столе работает пальцем; «нажал — нажал» тоже
- [ ] Обновить страницу посреди игры — прогресс на месте
- [ ] Повернуть телефон — игра не ломается, колонка остаётся по центру
- [ ] Свернуть и вернуться — звук замолкает и возвращается
- [ ] Переключить вкладку — звук замолкает
- [ ] Закрыть браузер и открыть снова — прогресс на месте
- [ ] Загрузка до первого экрана не дольше 5 секунд (желательно 3)
- [ ] Игра не тормозит (на глаз — плавные анимации)
- [ ] Звуки: короткие, не раздражают; переключатель «Звуки» в настройках работает

## 3. Черновик на Яндекс Играх (сборка `release`)

`npm run package`, загрузить архив в консоль, включить «Игра использует облачные сохранения».

- [ ] Игра загружается, консоль браузера без ошибок, нет уведомления о WebGL
- [ ] Язык: в русском интерфейсе Яндекс Игр — русский, в английском — английский
- [ ] Гость: играет и сохраняется без входа
- [ ] Настройки → «Войти через Яндекс»: окно входа появляется только по кнопке; после входа текст «Вы вошли…»
- [ ] После входа прогресс есть на другом устройстве с тем же аккаунтом
- [ ] Полноэкранная реклама: появляется после закрытия карточки находки, при входе на стол с главного экрана или при выходе из зоны — сразу, без задержки больше 2 секунд; не чаще раза в 3 минуты; не во время обучения
- [ ] Во время рекламы звук игры молчит, после неё возвращается; прогресс не теряется
- [ ] «Смотреть рекламу: +2 детали» на экране «Завал разобран!» — после просмотра +2 мелких детали, кнопка исчезает
- [ ] «Смотреть рекламу: +1 шайба» на столе — после просмотра шайба в первой свободной клетке; без места кнопки нет
- [ ] Если закрыть рекламу за вознаграждение раньше — награды нет, игра продолжается
