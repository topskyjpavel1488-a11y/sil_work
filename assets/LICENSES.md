# Ассеты и лицензии

Все графические и звуковые материалы игры перечисляются здесь: что это, откуда, кто автор, по какой лицензии (спецификация, раздел 2.3).

## Сейчас в игре

| Ключи | Что | Источник | Лицензия |
| --- | --- | --- | --- |
| `logo`, `find_*`, `final_card` | иллюстрации, сгенерированные нейросетью по промптам из `PROMPTS.md` | оригиналы в `assets/source/images/` | **уточнить:** сервис и тариф, право на коммерческое использование |
| остальные `images` в `manifest.json` | цветные прямоугольники-заглушки | рисуются кодом игры | сделаны для проекта |
| все `sounds` в `manifest.json` | короткие синтезированные тона | генерируются кодом через WebAudio | сделаны для проекта |
| фон по бокам на ПК | узор из полос (CSS в `index.html`) | код игры | сделан для проекта |

Сторонних файлов звука и шрифтов в игре нет; шрифт — системный.

Материалы для каталога (не в игре): `assets/store/store_icon.jpg`, `assets/store/store_cover.png` — сгенерированы нейросетью, сервис уточнить.

## Как добавлять

При подключении любого файла добавьте строку: ключ из `manifest.json`, описание, источник (ссылка или «сделано для проекта», автор), лицензия. Материалы без понятной свободной лицензии или подтверждённых прав не подключаются.
